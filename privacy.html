Privacy Policy

Effective date: 14 October 2026

Who uses these apps

This policy covers two private, single-user tools run by the channel owner: "SI Channel Uploader" (YouTube) and "How Superintelligence Actually Works Publisher" (TikTok).

YouTube tool

"SI Channel Uploader" is a private tool used only by the owner of the YouTube channel How Superintelligence Works to manage that channel. It is not offered to the public.

Data accessed

Through the YouTube Data API and YouTube Analytics API, the app accesses only the owner's own channel data: videos, video metadata (titles, descriptions, tags, thumbnails), captions, playlists, comments and channel analytics.

How data is used

Data is used only to upload and publish the channel's videos, manage their metadata and captions, and review the channel's performance.

Storage

OAuth tokens and working files are stored only on the owner's private computer and are never uploaded elsewhere.

Sharing

No data is shared, sold or used for advertising. The app does not collect any data from other users or viewers.

Retention and deletion

Data is kept only as long as needed to manage the channel. Tokens and stored data are deleted when the app is no longer used or on request to the contact address below.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok tool

"How Superintelligence Actually Works Publisher" is used only by the owner to post the channel's own videos to its own TikTok account @howsuperintellige via TikTok Login Kit and the Content Posting API. It accesses only: basic profile info (open ID, display name, avatar) to confirm the correct account, creator posting settings (allowed privacy levels, max video length), and upload/publish of our own video files with their captions. TikTok tokens are stored only on the owner's private computer. No TikTok data is sold, shared or used for advertising, and no data from other TikTok users is collected. Access can be revoked at any time in the TikTok app under Settings and privacy → Security → Apps and services.
