Privacy Policy

Effective date: 14 October 2026

Who uses this app

"SI Channel Uploader" is a private tool used only by the owner of the YouTube channel How Superintelligence Actually Works to manage that channel. It is not offered to the public.

Data accessed

Through the YouTube Data API and YouTube Analytics API, the app accesses only the owner's own channel data: videos, video metadata (titles, descriptions, tags, thumbnails), captions, playlists, comments and channel analytics.

How data is used

Data is used only to upload and publish the channel's videos, manage their metadata and captions, and review the channel's performance.

Storage

OAuth tokens and working files are stored only on the owner's private computer and are never uploaded elsewhere.

Sharing

No data is shared, sold or used for advertising. The app does not collect any data from other users or viewers.

Retention and deletion

Data is kept only as long as needed to manage the channel. Tokens and stored data are deleted when the app is no longer used or on request to the contact address below.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
